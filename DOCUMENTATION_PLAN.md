# Plan de Documentación del Proyecto - Don Elio

Este documento guía a cualquier desarrollador (o agente de IA) sobre cómo documentar este proyecto.

## Estructura de Documentación
1. **`README.md` (Raíz):**
   - Propósito del proyecto.
   - Stack tecnológico.
   - Arquitectura breve (Clean Architecture).
   - Instrucciones de configuración.

2. **`docs/ARCHITECTURE.md`:**
   - Diagrama de flujo de datos (Mermaid).
   - Explicación de las capas (Data, Domain, Presentation).

3. **Documentación Técnica (KDoc):**
   - Usar KDoc para componentes de UI complejos.
   - Usar KDoc para explicar lógica de negocio en `UseCase`.

4. **Seguimiento Vivo:**
   - **`Roadmap_Estado.md`:** Mantener actualizado.
   - **`CHANGELOG.md`:** Registrar hitos.
